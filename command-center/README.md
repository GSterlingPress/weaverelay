Canonical portfolio-level coordination layer. Created 2026-09-07 to stop project state from living only in parallel ChatGPT conversations.

## Rule
The Command Center ranks and routes work; it does not replace each project's own README/source of truth. Never store credentials or secrets here.

## Priority policy
1. Protect/finish live products and revenue paths.
2. Finish nearly-complete releases before starting new builds.
3. Respect explicit experiment firewalls and outcome-blind gates.
4. Park projects that have no immediate revenue/reliability reason to consume attention.
5. Every active project must have exactly one canonical next prompt.
