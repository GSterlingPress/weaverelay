# WeaveRelay public website

Standalone Early Access marketing site for **weaverelay.com**.

## Product promise

**CONNECT → MAP → DIAGNOSE**

WeaveRelay checks the systems behind an app, maps how they work together, and shows where something is broken.

## Early Access scope shown on this site

GitHub · Netlify · Railway · Supabase · Stripe

The five-PASS Studio One report is presented as a verified Client #1 proof. The failure-boundary card is explicitly labeled illustrative. No automatic repair capability is claimed.

## Safety boundary

This repository is standalone website code. It contains no Studio One credentials, provider tokens, customer data, or diagnostic backend code. It does not modify `GSterlingPress/studio-one-video`.

## Deploy

Static site. Compatible with Netlify. The Early Access form uses Netlify Forms and redirects to `/thanks.html`.
